# Airbnb 숙소 1박 가격 예측과 가격 경쟁력 숙소 추천

> 2026-2학기 2팀입니다.

아주대학교 2026년 2학기 **기계학습기초** 팀 프로젝트(2팀)입니다. 숙소의 위치, 유형, 수용 인원, 편의시설, 리뷰 정보로 1박 등록 가격을 예측하고, 예측 가격과 실제 가격의 차이를 이용해 비슷한 조건 중 가격 경쟁력이 높은 숙소를 찾는 것을 목표로 합니다.

**현재 단계: 아이디어 제안 완료, 데이터 수집 준비.** 아래 내용은 [프로젝트 제안서](<2026-2 기계학습기초 팀 프로젝트 Proposal(2team).pdf>)(2026-11-03)를 바탕으로 정리한 계획입니다. 아직 코드, 데이터, 모델, 실험 결과는 등록되어 있지 않습니다.

## 1. 프로젝트 개요

숙박 가격은 위치, 숙소 종류와 대여 방식, 편의시설, 이용자 평가 등 여러 요인에 따라 달라지기 때문에 소비자가 가격이 합리적인지 판단하기 어렵습니다. 이 프로젝트는 숙소 정보로 1박 가격을 예측하는 회귀 모델을 만들고, 여러 모델의 성능을 비교합니다.

| 항목 | 계획 |
| --- | --- |
| 프로젝트명 | Airbnb 숙소 1박 가격 예측과 가격 경쟁력 숙소 추천 |
| 입력 | 숙소의 위치, 숙소 종류, 대여 방식, 수용 인원, 편의시설, 리뷰 평점 등 |
| 예측 대상 | 숙소의 1박 등록 가격 (현지 통화 기준) |
| 문제 유형 | 지도학습 기반 회귀 |
| 비교 모델 | 선형회귀, 랜덤포레스트, XGBoost |
| 평가 지표 | MAE, RMSE, 결정계수(R²) |
| 활용 | 예측 가격과 실제 등록 가격을 비교해 가격 경쟁력이 높은 숙소 추천 |

```text
숙소 정보 → 전처리·EDA → 회귀 모델 3종 학습·비교 → 최종 모델 선정
                                              └ 예측 가격 vs 실제 가격 → 가격 경쟁력 높은 숙소 추천
```

## 2. 데이터 계획

[Inside Airbnb](https://insideairbnb.com/get-the-data/)에서 공개하는 도시별 숙소 데이터를 사용합니다.

| 항목 | 내용 |
| --- | --- |
| 데이터셋 | Inside Airbnb 도시별 공개 숙소 데이터 |
| 주 데이터 | `listings.csv.gz` (숙소별 상세 정보) |
| 보조 데이터 | `reviews.csv.gz` (상세 리뷰) |
| 예측 목표 | 숙소의 1박 등록 가격 |
| 피처 수 | 전처리 후 10개 이상 확보 예정 |
| 표본 수 | 전처리 후 숙소 1,000개 이상 확보 예정 |
| 라이선스 | CC BY 4.0 |

- `listings.csv.gz`에서 위치, 숙소 종류, 대여 방식, 수용 인원, 편의시설, 리뷰 평점 등을 입력 변수로 구성합니다.
- `reviews.csv.gz`에서 리뷰 특성을 추출하고, 리뷰 정보를 추가했을 때 예측 성능이 어떻게 바뀌는지 비교합니다.
- **분석할 도시와 데이터 수집 시점은 아직 정하지 않았습니다.** 확정되면 도시, 수집 시점, 다운로드 날짜를 이 표에 기록합니다.
- 원본 데이터는 저장소에 올리지 않을 계획입니다.

## 3. 방법과 평가 계획

### 전처리와 EDA

- 결측치와 이상치를 처리합니다.
- EDA로 위치, 숙소 유형, 편의시설, 리뷰 평점과 숙박 가격의 관계를 분석합니다.

### 모델 비교

| 모델 | 비고 |
| --- | --- |
| 선형회귀 | 기준 모델 |
| 랜덤포레스트 | 트리 앙상블(배깅) |
| XGBoost | 트리 앙상블(부스팅) |

- 모든 모델에 **같은 학습·검증·테스트 분할**을 적용합니다. 분할 비율과 seed는 데이터 확보 후 정합니다.
- **MAE, RMSE, R²**를 공통 평가 지표로 사용합니다.
- **Learning Curve**로 과적합 여부를 확인합니다.
- **Feature Importance**와 **SHAP**으로 가격 예측에 영향을 주는 주요 변수를 해석합니다.

### 가격 경쟁력 숙소 추천

최종 선정한 모델의 예측 가격과 실제 등록 가격을 비교해, 비슷한 조건의 숙소 중 상대적으로 가격 경쟁력이 높은 숙소를 추천합니다.

**아직 실험을 수행한 결과는 없습니다.** 모델별 점수, 최종 모델, 결과 그래프는 실험 후 추가합니다.

## 5. 실행 방법

현재는 제안서만 확인할 수 있습니다. 저장소는 다음과 같이 복제합니다.

```bash
git clone https://github.com/2026-2nd/2026-2-2.git
cd 2026-2-2
```

패키지 설치, 데이터 준비, 학습 명령은 코드가 추가되면 실제로 실행해 확인한 뒤 안내합니다. Python과 패키지 버전은 아직 정하지 않았으며, 구현할 때 `requirements.txt`에 기록합니다. **현재 실행 가능한 코드는 없습니다.**

## 6. 기대 효과와 한계

### 기대 효과

- 숙소의 위치, 유형, 편의시설, 리뷰 등 여러 특성과 숙박 가격의 관계를 분석할 수 있습니다.
- 여러 회귀 모델의 성능을 비교해 적합한 모델을 고를 수 있습니다.
- 예측 가격과 실제 가격의 차이를 이용해 소비자가 합리적인 가격의 숙소를 고르는 데 도움을 줄 수 있습니다.

### 한계

- 공개 데이터가 특정 지역과 수집 시점에 한정되어 다른 지역이나 시기에 대한 일반화 성능이 제한될 수 있습니다.
- 계절적 수요나 지역 행사 등 가격에 영향을 주는 외부 요인이 충분히 반영되지 않을 수 있습니다.
- 예측 가격이 숙소의 실제 가치를 뜻하지는 않으므로, 추천 결과는 보조적인 판단 기준으로만 활용해야 합니다.
